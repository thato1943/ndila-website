# Approved website photos

Upload only photographs that Ndila has permission to publish. Do not place customer enquiries, identity documents, contracts, private client records or confidential auction material in this public repository.

Use descriptive file names with hyphens, for example `asset-yard-01.jpg`. In a confirmed listing, use image paths such as `images/asset-yard-01.jpg` and write a short, accurate alt description. The gallery accepts JPG, JPEG, PNG, WebP and AVIF files.
